6. 🎁 TRAP에 없는 추가 발견

호스트 인벤토리에 없지만 우리 리뷰가 잡은 진짜 문제들 (꼼꼼함 보너스).
  • 인덱스 부재 (PERF-2) — TRAP #3은 N+1만, 우리는 asset_id/returned_at/user_id 인덱스 부재까지 결합 분석.
  • ReturnExtend 프론트 N+1 (PERF-4) — 대여 건마다 자산 상세 직렬 fetch, reload마다 재폭격.
  • CSRF 보호 부재 (UNPLANNED-3) — PATCH 상태변경 엔드포인트, 쿠키 인증 전환 시 악화.
  • 연장 상한 계산 결함 (UNPLANNED-2) — started_at 기준 재계산이라 반복 연장 시 한도 우회 가능.
  • 페이지네이션 부재 (PERF-3) — 무한 증가 rental 이력을 limit 없이 반환.
  • 타임존 naive/aware 불일치 — DB naive 저장 vs datetime.now(UTC) aware.
  • next_available_at 직렬화 타입 불일치 (ARCH-5) — 다른 DTO는 datetime, 여기만 str.

7. 🔗 결합 시나리오

단독 평가의 합이 아닌 시너지 — 합의 종합 단계의 핵심 가치.
  • COMBO-1 Stored XSS → userId 탈취 → IDOR 대량 반납 = Critical (#2+#1+#9 결합).
  • COMBO-2 N+1 + 인덱스 부재 + 페이지네이션 부재 = availability 타임아웃 = Critical.
  • COMBO-3 SSOT 위반 → 데이터 불일치 → 권한·가용 판정 오류 (#5+#1).
