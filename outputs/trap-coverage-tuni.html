7. 🔗 결합 시나리오 (Combined Risks)

[COMBO-1] XSS → 콘솔 dump 흡수 → userId 탈취 → IDOR 대량 반납 Critical 체인
결합 발견: 트랩 #2 (XSS) + 트랩 #9 (handleError 정보 노출) + 트랩 #1 (return IDOR). 단독은 High + Medium + Critical이지만 체인이 무인 자동화를 가능하게 만들어 Critical로 승격. 5단계 공격 경로를 통합 리포트가 시퀀스로 명시. 트랩 #3 (이중 상태)이 후속 재대여 통과를 도와 체인 길이를 추가로 늘림.
[COMBO-2] 순차 ID + 반납 IDOR + availability/all 인증 부재 = 정찰→대량 탈취 High
결합 발견: 트랩 #1 (Critical) + UNPLANNED-1 (Medium, 인증 없는 due_at 노출). 인증 없이 활성 대여 목록을 수집한 뒤 순차 정수 ID로 정밀 강제 반납. 통합 리포트가 별도 권고로 Depends(current_user) 추가도 명시.
